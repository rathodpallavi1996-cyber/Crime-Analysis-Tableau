# Crime Analysis Dashboard – Tableau

## Project Overview

An interactive Tableau dashboard built to analyze crime patterns, trends, locations, and time-based activity using historical crime data.

This project was completed as part of my Tableau project work.

## Problem Statement

The objective of this project is to analyze historical crime data and build an interactive Tableau dashboard to identify crime patterns, trends, locations, time-based activity, and arrest outcomes.

The analysis focuses on:
- Common crime types and incident patterns
- Crime locations and geographical distribution
- Crime activity by day and hour
- Year-wise crime trends
- Arrest vs. non-arrest patterns
- Crime patterns by location and incident type

## Business Questions

- What are the most common types of crimes?
- Where are crime incidents concentrated?
- How do crime patterns change by day and hour?
- How have crime incidents changed over the years?
- How do arrest rates vary across crime categories?
- What patterns can be identified through geographic analysis?

## Key Analysis

- Overall crime statistics
- Crime type analysis
- Geographic crime mapping
- Day and hour analysis
- Year-wise crime trends
- Arrest vs. non-arrest analysis
- Interactive filters for crime type and location
